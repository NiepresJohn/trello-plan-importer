How it works

Three steps from idea to board.

Generate

Pick a provider and describe your project, or switch to Paste JSON and load an existing plan.

Import & review

Choose a board, toggle replace mode, then edit titles, dates, labels and checklists card by card.

Commit to Trello

Confirm, watch real-time progress, and open each card in Trello.

Two JSON formats

Use whichever your LLM produces — it's normalized for you.

Simple — flat task list
{
  "boardName": "Website Redesign",
  "listName": "To Do",
  "items": [{
    "name": "Design homepage mockup",
    "desc": "3 variations for A/B testing",
    "due": "2026-03-15T17:00:00Z",
    "labels": ["P0", "Design"],
    "checklist": ["Sketch wireframes",
                  "Get feedback"]
  }]
}
Board — multi-list
{
  "board": {
    "name": "Mobile App Launch",
    "labels": [{ "id": "l1", "name": "P0",
                 "color": "red" }],
    "lists": [{
      "name": "Backlog",
      "cards": [{ "title": "Research competitors",
                  "labelIds": ["l1"] }]
    }]
  }
}

FieldLimitDescription
namerequired, 500 charsCard title
desc5000 charsCard description
dueISO 8601Due date
labelsmax 10Names or { name, color }
checklistmax 50Subtask strings
listName—Override list for this card

Colors: yellow purple blue red green orange black sky pink lime. Aliases like title→name, description→desc, columns→lists work too.

Setup in minutes

Node 18+ and a Trello account. Get your key and token at trello.com/app-key.

git clone https://github.com/NiepresJohn/trello-plan-importer.git
cd trello-plan-importer
npm install
cp .env.example .env.local     # then fill in credentials
npm run dev                    # → http://localhost:3000
